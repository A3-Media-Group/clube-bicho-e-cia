Atualização: 13/09/2026.

O que acontece com seus dados

Os campos das ferramentas são processados no seu navegador. Este código não envia os valores a um servidor, não cria contas e não usa cookies, armazenamento local, analytics ou pixels de publicidade. Ao recarregar a página, os resultados não são mantidos pelo site; seu navegador pode restaurar campos conforme suas próprias preferências.

Arquivos e links

O lembrete .ics é criado no seu dispositivo. Se você o importar em outro aplicativo, passam a valer as políticas desse serviço. Fotografias, estilos e scripts são servidos junto com o site. Links externos só levam você ao serviço de destino quando acessados.

Hospedagem

O provedor que hospeda o site pode tratar informações técnicas de conexão, como endereço IP e registros de acesso, conforme sua própria política. Em uma publicação no GitHub Pages, consulte a política do GitHub ↗.

Mudanças futuras

A inclusão de anúncios, formulários ou medição de audiência exige atualizar esta página e informar os serviços efetivamente usados. Esta versão não os ativa. Para solicitações relativas à publicação, utilize o canal disponibilizado pelo responsável no repositório, evitando dados pessoais em Issues públicas.
